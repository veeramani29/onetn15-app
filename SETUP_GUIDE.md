## 🚀 Build and Start Commands

### **Frontend Commands** (from root directory)

#### 1. **`npm start`** - Start Development Server
```bash
npm start
```
- Starts React development server on port 3000
- Hot-reload enabled (changes auto-refresh)
- Uses webpack-dev-server
- Proxies API calls to backend via setupProxy.js
- **Note:** In this environment, the dev server doesn't start the HTTP listener properly

#### 2. **`npm run build`** - Build for Production
```bash
npm run build
```
- Creates optimized production build in `/build` directory
- Minifies and bundles all assets
- Generates source maps for debugging
- Output: `/build/static/js/main.*.js` and `/build/static/css/main.*.css`

#### 3. **`npm test`** - Run Tests
```bash
npm test
```
- Launches test runner in watch mode
- Runs tests in `/src/**/*.test.js`

### **Backend Commands** (from root directory)

#### 1. **`npm run server`** - Start Backend Server
```bash
npm run server
```
- Installs backend dependencies
- Starts Node.js/Express server on port 3001
- Serves both API and frontend (from `/build` directory)
- Requires database to be set up first

#### 2. **`npm run db:setup`** - Setup Database
```bash
npm run db:setup
```
- Runs PostgreSQL schema setup
- Creates tables: users, categories, subcategories, news, media
- Inserts sample data

### **Combined Commands**

#### 1. **`npm run dev`** - Start Both Frontend & Backend
```bash
npm run dev
```
- Requires `concurrently` package (not installed by default)
- Runs both `npm run server` and `npm start` in parallel
- Frontend on port 3000, Backend on port 3001

## 🔧 How to Run the App

### **Option 1: Production Mode (Recommended)**
```bash
# 1. Build the frontend
npm run build

# 2. Start the backend server (serves both API and frontend)
npm run server
```
- Access app at: **http://localhost:3001**
- Backend API at: **http://localhost:3001/api**

### **Option 2: Development Mode**
```bash
# Terminal 1: Start backend
npm run server

# Terminal 2: Start frontend dev server
npm start
```
- Frontend at: **http://localhost:3000**
- Backend API at: **http://localhost:3001/api**
- Proxy configured in `setupProxy.js`

## 📝 Important Notes

1. **Port 3000 Dev Server Issue:** The React dev server (`npm start`) may not properly start the HTTP listener in this environment. Use production build instead.

2. **Production Build:** Always run `npm run build` before deploying to ensure latest changes are included.

3. **Database:** PostgreSQL must be running before starting the backend server.

4. **Error Boundary:** App has error boundary for better error handling and debugging.

5. **CORS:** Backend allows requests from `http://localhost:3000` and `http://localhost:3001`.
