# ONETN15 App - Deployment Guide

## 🚀 Deploying to Render.com

### Prerequisites
- GitHub repository with code pushed
- Render.com account
- PostgreSQL database (Render provides free tier)

### Deployment Steps

#### 1. **Connect GitHub Repository**
- Go to [Render Dashboard](https://dashboard.render.com)
- Click "New +" → "Web Service"
- Connect your GitHub account
- Select `veeramani29/onetn15-app` repository
- Choose `main` branch

#### 2. **Configure Build Settings**
The `render.yaml` file is already configured with:
- **Build Command:** `npm install && npm run build && cd server && npm install`
- **Start Command:** `cd server && node index.js`
- **Node.js Version:** 22.22.2 (specified in `.nvmrc`)

#### 3. **Environment Variables**
Render will automatically set:
- `NODE_ENV=production`
- `DATABASE_URL` (from PostgreSQL database)
- `JWT_SECRET` (auto-generated)
- `PORT=3001`

#### 4. **Database Setup**
- Render creates PostgreSQL database automatically
- Database name: `cms_db`
- User: `postgres`

#### 5. **Post-Deployment**
After deployment, you need to:

1. **Run database schema:**
   ```bash
   # SSH into Render service
   psql $DATABASE_URL -f server/schema.sql
   ```

2. **Create admin user:**
   ```bash
   # SSH into Render service
   cd server && node setup.js
   ```

## 🔧 Troubleshooting Deployment

### Issue: "react-scripts: not found"
**Solution:** Make sure `npm install` runs before build
- Check `render.yaml` buildCommand includes `npm install`
- Verify `package.json` is in root directory
- Check `package-lock.json` exists

### Issue: Database connection fails
**Solution:** 
- Verify `DATABASE_URL` environment variable is set
- Run schema setup after deployment
- Check database credentials in `.env`

### Issue: Build takes too long
**Solution:**
- Render free tier has 30-minute build limit
- Consider upgrading to paid plan
- Optimize dependencies in `package.json`

### Issue: Port 3001 not accessible
**Solution:**
- Render assigns a random port via `PORT` env var
- App automatically uses `process.env.PORT`
- Check Render dashboard for assigned port

## 📊 Build Process

The deployment follows this order:

1. **Install frontend dependencies**
   ```bash
   npm install
   ```

2. **Build React app**
   ```bash
   npm run build
   ```

3. **Install backend dependencies**
   ```bash
   cd server && npm install
   ```

4. **Start backend server**
   ```bash
   cd server && node index.js
   ```

## 🔐 Security Notes

- Never commit `.env` file
- JWT_SECRET is auto-generated by Render
- Database password is managed by Render
- Use HTTPS only (Render provides SSL)
- Enable CORS for your domain
